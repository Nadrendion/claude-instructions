# End a session

1. **Check that nothing is half-done:** uncommitted changes, unmerged branches, open pull requests. If there are any, say so and ask what to do before ending.
2. **Update the progress notes** with where things stand.
3. **List the next logical steps,** three to five, from the milestones, open issues and notes, each with one line on why.
4. **Recommend one,** with the reason.
5. **When the user picks one, write a startup prompt** for the new session, in a `text` code block, so the user can copy it with the copy button. It names the issue with a link, what's already decided, what's still open, where to look, and which skill to start with. Keep it short, and don't repeat what the notes and docs already hold.
6. **Mention anything running** that stops with the session, such as dev servers.
