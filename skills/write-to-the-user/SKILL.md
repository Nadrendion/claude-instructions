# Write to the user

- Use plain words. Name issues and pull requests by their title, with a link, never a bare number.
- Lead with what's now true. Mark what wasn't checked or isn't done.
- Ask only about what's really the user's call, one decision at a time, with a recommendation first.
- Show text, such as issues, pull requests and decisions, before creating it.
- Quote screen text exactly, in the language the user sees.
